## 직접 다룬 문제

Web·Misc·OSINT 등 여러 분야의 문제를 분석했습니다. 아래 기록은 개인이 확인한 범위와 팀의 해결 상태를 나누어 정리한 것입니다.

- **php2shell (real) · Web:** PHP·WordPress 환경을 분석하고 로컬에서 일부 버전의 RCE를 검증했습니다. 마지막 라이브 그룹의 토큰 세 개는 확보하지 못했습니다.
- **You Got Calc’d? · Misc:** 계산식 API의 입력과 백엔드 경계를 조사했습니다. 개인 조사에서는 플래그 경로를 확인하지 못했으며, 팀은 Redis 응답 처리 결함을 연구한 뒤 해결했습니다.
- **Will be there OSINT? · OSINT:** 사진의 촬영 위치를 마운트 존 천문대 주변으로 좁혔고, 이후 팀원이 정답 위치를 확인했습니다.
- **flag.png · Misc:** 텍스트와 이미지 자료를 분석했지만 개인 조사에서는 복원하지 못했습니다. 팀은 PNG→ELF 변환과 재사용 키스트림을 이용해 해결했습니다.
- **mathclipse · Misc:** 제한된 Python 실행 환경을 다루는 문제를 분석했습니다. 팀 기록에서 δ 변형의 완료 알림과 풀이 메모를 확인했습니다.
- **VulCreator · Misc:** Windows 드라이버의 권한·TDI 동작을 추적했습니다. 개인 분석에는 미확정 부분이 있었으며, 이후 팀 채널에 해결 표기가 남았습니다.
- **litter:** 랜섬웨어로 암호화된 이미지의 헤더와 복호화 후보를 조사했으나 개인 분석에서는 정답을 확인하지 못했습니다.
