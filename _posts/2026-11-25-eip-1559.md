EIP-1559는 이더리움의 거래 수수료, 즉 가스비가 결정되고 지급되는 방식을 개선한 제안이다.<br />(가스비 == 실행에 드는 수수료)

#### 배경 개념 - 가스비

이더리움에서 다음과 같은 작업을 실행하려면 계산 자원이 필요하다.

```py
ETH 전송
ERC-20 토큰 전송
NFT 발행
스마트 컨트랙트 실행
DEX에서 토큰 교환
```

사용자는 이 계산 비용을 가스비로 지불하게 된다.

#### 왜 등장했을까?

분명 EIP-1559가 만들어진 이유는 무언가 문제가 있어서 만들어졌을 것이다.<br />이전에는 사용자가 원하는 가스 가격을 제시하는 경매 방식이 사용되었다.

하지만 이 방식은 아래와 같은 문제를 만들었다.

1. 가스비를 예측하기 어려움 : 너무 낮게 설정하면 오랫동안 처리되지 않고, 너무 높으면 필요 이상의 수수료를 지불함
2. 갑작스러운 혼잡에 대응하기 힘듦 : 인기 프로젝트 출시로 거래가 몰리면 사용자들이 서로 더 높은 가스비를 제시하면서 수수료가 급격히 상승함
3. 모든 수수료가 블록 생산자에게 지급됨 : 수수료가 ETH의 가치나 공급 구조에는 직접적으로 반영되지 않음

#### 핵심 동작 방식

1559는 거래 수수료를 크게 두 부분으로 나눴다.

```py
실제 가스 가격 = 기본 수수료 + 우선 수수료
```

기본 수수료

- 네트워크가 블록의 혼잡도에 따라 자동으로 결정하는 가격이다.
  - 블록 사용량이 높으면 다음 블록의 Base Fee가 상승
  - 블록 사용량이 낮으면 다음 블록의 Base Fee가 하락
  - 사용자가 임의로 정하는 가격이 아님
  - 지불된 Base Fee는 소각됨

우선 수수료

- 거래를 처리해 준 검증자에게 지급하는 추가 수수료(팁이라고 부름)
- 높은 우선 수수료를 설정하면 거래가 더 빨리 처리될 가능성이 높음

#### 핵심 항목 - Max Fee

사용자는 거래를 보낼 때 자신이 지불할 수 있는 최대 가스 가격을 지정할 수 있다.

- maxFeePerGas: 가스 하나당 지불할 최대 금액
- maxPriorityFeePerGas: 검증자에게 줄 최대 팁

#### 핵심 항목 - Base Fee

EIP-1559는 각 블록에 <b>목표 가스 사용량을 둔다.</b>

```py
블록 사용량 > 목표량 → 다음 블록 Base Fee 상승
블록 사용량 < 목표량 → 다음 블록 Base Fee 하락
블록 사용량 = 목표량 → Base Fee 유지
```

블록은 일시적으로 목표량의 최대 두 배까지 가스를 사용할 수 있다.<br />그래서 갑자기 거래가 몰려도 일부 거래를 더 수용할 수 있다.

블록이 최대치까지 찬 경우 다음 블록의 Base Fee는 최대 12.5% 상승할 수 있다.<br />반대로 블록이 비어 있으면 최대 12.5% 하락할 수 있다.

#### 주의할 점

EIP-1559는 가스비를 무조건 낮추는 제안이 아니다.<br />네트워크가 혼잡하면 Base Fee가 올라가기 때문에 가스비는 여전히 비싸질 수 있으며, 핵심 목적은 수수료를 더 예측하기 쉽게 만드는 것이다.

#### 실제 이더리움 메인넷 사례 - 타입 2 트랜잭션

EIP-1559는 특정 컨트랙트가 아니라 이더리움의 수수료 규칙이기 때문에 실제 트랜잭션에서 확인해야 한다.

- [EIP-1559 트랜잭션 Etherscan에서 확인하기](https://etherscan.io/tx/0xd2c4de9d899433f4fcbd742c8cf323b5db5df42bb1ed20059db0d58d74ec206e)

해당 트랜잭션의 상세 정보에서는 Txn Type 2 (EIP-1559), Base Fee, Max Fee, Max Priority Fee를 확인할 수 있다.<br />이를 통해 기본 수수료와 검증자에게 지급되는 우선 수수료가 구분되어 처리되는 것을 확인할 수 있다.

#### 한 줄 정리

> EIP-1559는 가스비를 기본 수수료와 우선 수수료로 나누고, 기본 수수료를 소각하도록 만든 수수료 개선안이다.
