ERC-721은 이더리움에서 고유한 토큰, 즉 NFT를 만들기 위한 표준이다.<br />ERC-20 토큰은 같은 종류의 토큰끼리 동일하지만, ERC-721 토큰은 각각 고유한 tokenId를 가진다.

> ERC-721은 고유한 디지털 자산의 소유권과 전송 방법을 정의한 스마트 컨트랙트 표준이다.

공식 EIP 번호는 EIP-721이며 일반적으로 ERC-721이라고 부른다.

#### 배경 개념 - NFT(<b>Non-Fungible Token</b>)

대체 불가능한 토큰이라는 뜻이다.<br />(각각의 토큰을 서로 동일한 자산으로 취급할 수 없다는 뜻)

#### 왜 등장했을까?

ERC-20은 토큰의 수량을 관리하는 데 적합하지만, 고유한 자산을 개별적으로 구분하기는 어렵기 때문이다.<br />각 자산의 특징과 소유자를 개별적으로 구분해야 해서 ERC-721은 각 토큰에 고유한 번호인 tokenId를 부여하는 것이다.

#### 핵심 동작 방식

NFT도 사용자 지갑 안에 이미지 파일로 들어 있는 것이 아니며 스마트 컨트랙트가 정보를 기록한다.

```solidity
어떤 tokenId가 존재하는가?
각 tokenId의 소유자는 누구인가?
누가 해당 NFT를 전송할 권한을 가졌는가?
해당 NFT의 메타데이터는 어디에 있는가?
```

지갑은 NFT 컨트랙트에 ownerOf(100)을 호출해서 100번 NFT의 소유자를 확인하는 방식으로 사용한다.

#### 핵심 함수

ERC-721 토큰들이 공통으로 사용하는 핵심 함수는 다음과 같다.

- <b>balanceOf()</b> : 특정 주소가 가진 NFT의 개수를 조회
- <b>ownerOf()</b> : 특정 tokenId를 가진 NFT의 소유자를 조회
- <b>transferFrom()</b> : 특정 NFT를 다른 주소로 전송
- <b>safeTransferFrom()</b> : 받는 주소가 NFT를 받을 수 있는지 확인한 뒤 안전하게 전송

transferFrom()은 NFT를 바로 전송하지만, safeTransferFrom()은 받는 주소가 스마트 컨트랙트라면 NFT를 정상적으로 받을 수 있는지 확인한다.<br />NFT가 처리할 수 없는 스마트 컨트랙트에 갇히는 것을 막기 위한 기능이라고 할 수 있다.

#### 권한 부여

소유자는 다른 주소 또는 마켓플레이스가 NFT를 대신 전송하도록 승인할 수도 있다.

approve() : 특정 NFT 하나의 전송 권한을 부여하는 역할

```solidity
function approve(
    address approved,
    uint256 tokenId
) external;
```

<b>getApproved() : </b>특정 NFT의 전송 권한을 받은 주소를 조회

```solidity
function getApproved(uint256 tokenId)
    external
    view
    returns (address);
```

<b>setApprovalForAll() : </b>소유자가 가진 해당 컬렉션의 모든 NFT를 관리할 권한을 부여하는 것

```solidity
function setApprovalForAll(
    address operator,
    bool approved
) external;
```

<b>isApprovedForAll() :</b>운영자가 전체 NFT에 대한 권한을 받았는지 확인하는 역할

```solidity
function isApprovedForAll(
    address owner,
    address operator
) external view returns (bool);
```

#### NFT 발행과 소각

<b>민팅(Minting)</b>

- 새로운 NFT를 생성하고 소유자를 지정하는 과정이다.

```solidity
존재하지 않던 NFT #100
        ↓ 민팅
NFT #100의 소유자 = 사람1
```

<b>소각(Burning)</b>

- 기존 NFT를 더 이상 유효하지 않도록 만드는 과정

```solidity
NFT #100
사람1 소유
   ↓ 소각
더 이상 유효한 NFT가 아님
```

#### NFT 이미지와 메타데이터

NFT를 가지고 있다고 해서 이미지 파일이 사용자의 지갑이나 이더리움 블록체인에 직접 들어 있는 것은 아니다.<br />ERC-721에서는 일반적으로 tokenURI()라는 함수를 이용해 NFT의 메타데이터 위치를 알려준다.

```solidity
NFT 컨트랙트
      ↓ tokenURI()
메타데이터 JSON
      ↓ image
NFT 이미지
```

메타데이터에는 NFT의 이름, 설명, 이미지 주소, 속성 등이 들어갈 수 있다.<br />이미지와 메타데이터는 IPFS, 프로젝트 서버 또는 블록체인 내부에 저장될 수 있다.

그래서 NFT를 소각해도 컨트랙트의 소유권 기록이 사라지는 것이지, 외부에 저장된 이미지 파일까지 자동으로 삭제되는 것은 아니다.

#### 주의할 점

setApprovalForAll()은 해당 컬렉션의 모든 NFT를 관리할 수 있는 강력한 권한이다.<br />악성 사이트에 이 권한을 승인하면 여러 NFT가 탈취될 수 있으며, 메타데이터가 프로젝트 서버에만 저장된 경우 서버가 사라지거나 내용이 변경될 가능성도 있다.

Bored Ape Yacht Club(BAYC)은 이더리움 메인넷에 배포된 대표적인 ERC-721 NFT 컬렉션이다.

- 컨트랙트 주소 : <code>0xBC4CA0EdA7647a8ab7C2061c2E118A18a936f13D</code>
- [BAYC Etherscan에서 확인](https://etherscan.io/token/0xbc4ca0eda7647a8ab7c2061c2e118a18a936f13d)

BAYC는 하나의 ERC-721 컨트랙트에서 여러 NFT를 관리하지만, 각각의 NFT는 서로 다른 tokenId와 소유자를 가진다.<br />Etherscan에서는 NFT별 tokenId, 현재 소유자, 과거 전송 기록을 확인할 수 있다.

#### 한 줄 정리

> ERC-721은 각각의 토큰에 고유한 tokenId를 부여하고 소유권과 전송 방법을 정의한 NFT 표준이다.
