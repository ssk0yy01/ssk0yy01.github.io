ERC-20은 이더리움에서 대체 가능한 토큰을 만들기 위한 공통 규칙이다.<br />여기서 토큰은 이더리움 위의 스마트 컨트랙트가 관리하는 디지털 자산을 뜻한다.

> ERC-20은 토큰 자체가 아니라, 토큰 스마트 컨트랙트가 따라야 하는 표준

공식 EIP 번호는 <b>EIP-20</b>이지만, 일반적으로 ERC-20이라고 부른다.

#### 배경 개념 - 대체 가능한 토큰

대체 가능하다는 것은 같은 종류의 토큰들이 서로 동일한 가치와 성질을 가진다는 뜻이다.<br />이건 약간 비유해 보자면 현실의 화폐와 비슷하다고 할 수 있다.

```py
내 만 원권 1장 ≈ 다른 사람의 만 원권 1장
```

#### 왜 등장했을까?

ERC-20 이전에 개발자들이 각자 다른 방식으로 토큰을 만들었다면, 모든 서비스가 토큰마다 별도의 연결 방법을 개발해야 했을 것이다.

예를 들어 토큰마다 전송 함수 이름이 모두 달랐을 수 있다.<br />그러면 지갑이나 거래소는 토큰마다 사용법을 별도로 알아야 하는 문제점이 생긴다.

ERC-20은 이러한 함수들의 공통된 이름과 동작 방식을 정의하기 위해 만들어졌다.

```solidity
transfer(...)
balanceOf(...)
approve(...)
transferFrom(...)
```

따라서 새로운 ERC-20 토큰이 등장해도 지갑과 거래소가 같은 방식으로 연결할 수 있는 것이다.

#### 핵심 동작 방식

ERC-20 토큰은 사용자 지갑 안에 파일처럼 들어 있는 것이 아니다.<br />토큰 스마트 컨트랙트가 주소별 잔액을 기록한다.

```solidity
mapping(address => uint256) private balances;
```

이 정보를 확인하기 위해 메타마스크는 토큰 컨트랙트에 질문을 하게 된다.

```solidity
이 주소가 가진 토큰은 몇 개인가?
```

토큰 컨트랙트의 balanceOf()가 그 결과를 반환하고, 메타마스크가 이를 화면에 표시한다.

#### 핵심 함수

ERC-20 토큰들이 공통으로 사용하는 핵심 함수는 다음과 같다.

- <b>totalSupply()</b> : 현재 발행된 전체 토큰의 수량을 조회
- <b>balanceOf()</b> : 특정 주소가 가진 토큰의 수량을 조회
- <b>transfer()</b> : 자신의 토큰을 다른 주소로 전송
- <b>approve()</b> : 다른 주소나 스마트 컨트랙트에 토큰 사용 권한을 부여
- <b>allowance()</b> : 부여된 토큰 사용 한도를 조회
- <b>transferFrom()</b> : 승인받은 주소가 소유자를 대신해 토큰을 전송

여기서 balanceOf()와 allowance()는 정보를 조회하는 함수이고, transfer(), approve(), transferFrom()은 블록체인의 상태를 변경하기 때문에 트랜잭션과 가스비가 필요하다.

#### 권한 부여 - approve()

스마트 컨트랙트는 사용자의 지갑에서 마음대로 토큰을 가져갈 수 없다.<br />그래서 사용자가 먼저 사용 권한을 줘야 한다.

```solidity
사용자
  │
  ├─ approve: DEX가 100개까지 사용해도 됨
  │
  └─ swap 요청
         ↓
      DEX가 transferFrom 실행
```

이 구조 덕분에 DEX, 대출 서비스, 게임 등의 스마트 컨트랙트가 사용자 동의 아래 토큰을 사용할 수 있는 것이다.

다만 무제한 승인을 허용하면 해당 서비스가 해킹됐을 때 많은 토큰이 탈취될 수 있으므로 주의해야 한다.

#### 핵심 이벤트

ERC-20은 중요한 동작을 블록체인 로그에 남기도록 이벤트도 정의한다.

<b>Transfer : </b>토큰이 이동하거나 발행, 소각될 때 기록

```solidity
event Transfer(
    address indexed from,
    address indexed to,
    uint256 value
);
```

<b>Approval</b> : 토큰 사용 권한이 설정될 때 기록

```solidity
event Approval(
    address indexed owner,
    address indexed spender,
    uint256 value
);
```

#### 사용 사례

ERC-20은 다양한 종류의 자산에 사용된다.

```solidity
스테이블코인: USDC, USDT, DAI
거버넌스 토큰: UNI, AAVE
서비스 토큰: LINK
게임 내 화폐
프로젝트 보상 포인트
스테이킹 및 유동성 관련 토큰
```

ERC-20을 따르기 때문에 이러한 토큰들을 메타마스크, 거래소와 디파이 서비스가 공통된 방식으로 처리할 수 있다.

#### 실제 이더리움 메인넷 사례 - USDC

USDC는 실제 이더리움 메인넷에서 사용되고 있는 대표적인 ERC-20 스테이블코인이다.

- 컨트랙트 주소 : <code>0xA0b86991c6218b36c1d19d4a2e9eb0cE3606eB48</code>
- 소수점 자릿수(decimals) : 6
- [USDC Etherscan에서 확인하기](https://etherscan.io/token/0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48)

Etherscan의 Token Transfers에서는 실제 USDC 전송 기록을 볼 수 있고, Contract 메뉴에서는 balanceOf(), transfer(), approve(), allowance()와 같은 ERC-20 관련 함수를 확인할 수 있다.

즉, ERC-20이라는 공통 규칙 덕분에 USDC도 메타마스크, 거래소, DEX 등에서 별도의 전송 방식을 새로 만들지 않고 같은 방식으로 사용할 수 있는 것이다.

#### 한 줄 정리

> ERC-20은 대체 가능한 토큰의 잔액, 전송, 사용 권한을 공통된 방식으로 관리하기 위한 표준이다.
