ERC-1155는 하나의 스마트 컨트랙트에서 여러 종류의 토큰을 함께 관리할 수 있도록 만든 표준이다.<br />ERC-20처럼 수량을 가진 토큰과 ERC-721처럼 고유한 NFT를 하나의 컨트랙트 안에서 모두 표현할 수 있다.

> ERC-1155는 여러 종류의 토큰과 수량을 tokenId별로 관리하는 멀티 토큰 표준이다.

공식 EIP 번호는 <b>EIP-1155</b>이며 일반적으로 ERC-1155라고 부른다.

#### 배경 개념 - 멀티 토큰

멀티 토큰은 하나의 컨트랙트에서 서로 다른 종류와 수량의 토큰을 함께 관리하는 방식이다.<br />각 토큰은 tokenId로 구분되며, 같은 tokenId의 토큰은 여러 개 존재할 수도 있다.

#### 왜 등장했을까?

ERC-20은 하나의 컨트랙트에서 한 종류의 대체 가능한 토큰을 관리하는 데 적합하고, ERC-721은 각각 고유한 NFT를 관리하는 데 적합하다.

하지만 게임처럼 여러 종류의 아이템과 화폐를 함께 사용한다면 각각의 토큰마다 별도의 컨트랙트를 배포해야 할 수 있다.

```solidity
게임 골드 → ERC-20 컨트랙트
회복 물약 → 또 다른 토큰 컨트랙트
전설의 검 → ERC-721 컨트랙트
방어구 → 또 다른 ERC-721 컨트랙트
```

ERC-1155를 이용하면 이러한 자산들을 하나의 컨트랙트에서 서로 다른 tokenId로 관리할 수 있다.

```solidity
tokenId 1 → 게임 골드
tokenId 2 → 회복 물약
tokenId 3 → 전설의 검
tokenId 4 → 방어구
```

하나의 컨트랙트만 배포하면 되고 여러 토큰을 한 번에 전송할 수도 있기 때문에 컨트랙트 관리와 가스비 측면에서 효율적이다.

#### 핵심 동작 방식

ERC-1155에서는 하나의 주소가 특정 tokenId를 몇 개 가지고 있는지 기록한다.

```solidity
사람1
├── tokenId 1 : 게임 골드 100개
├── tokenId 2 : 회복 물약 5개
└── tokenId 3 : 전설의 검 1개
```

같은 tokenId를 여러 개 발행하면 ERC-20과 비슷한 대체 가능한 토큰처럼 사용할 수 있고, 발행 수량을 1개로 제한하면 ERC-721과 비슷한 고유한 NFT처럼 사용할 수 있다.

#### 핵심 함수

ERC-1155 토큰들이 공통으로 사용하는 핵심 함수는 다음과 같다.

- <b>balanceOf()</b> : 특정 주소가 특정 tokenId를 몇 개 가지고 있는지 조회
- <b>balanceOfBatch()</b> : 여러 주소와 tokenId의 잔액을 한 번에 조회
- <b>safeTransferFrom()</b> : 특정 tokenId의 토큰을 원하는 수량만큼 전송
- <b>safeBatchTransferFrom()</b> : 여러 종류의 토큰을 한 번에 전송
- <b>setApprovalForAll()</b> : 다른 주소나 스마트 컨트랙트에 모든 토큰의 관리 권한을 부여
- <b>isApprovedForAll()</b> : 전체 관리 권한이 부여되었는지 확인

ERC-721은 특정 tokenId 하나를 전송하지만, ERC-1155는 tokenId와 amount를 함께 전달한다.

```solidity
safeTransferFrom(
    from,
    to,
    id,
    amount,
    data
);
```

그래서 같은 종류의 아이템을 여러 개 보낼 수 있고, safeBatchTransferFrom()을 이용하면 서로 다른 종류의 아이템도 하나의 트랜잭션으로 전송할 수 있다.

#### 안전한 전송

ERC-1155의 전송 함수에 safe라는 이름이 들어가는 이유는 받는 주소가 스마트 컨트랙트일 때 토큰을 정상적으로 받을 수 있는지 확인하기 때문이다.

받는 컨트랙트가 ERC-1155 토큰을 처리할 수 없다면 전송을 실패시켜 토큰이 컨트랙트에 갇히는 것을 방지한다.

#### 권한 부여 - setApprovalForAll()

ERC-1155에서는 setApprovalForAll()을 이용해 마켓플레이스나 게임 컨트랙트에 토큰 관리 권한을 줄 수 있다.

```solidity
사용자
  │
  ├─ setApprovalForAll(마켓플레이스, true)
  │
  └─ 마켓플레이스가 사용자의 ERC-1155 토큰을 전송
```

이 권한은 특정 tokenId 하나가 아니라 해당 ERC-1155 컨트랙트 안에서 사용자가 가진 모든 토큰에 적용된다.

#### 주의할 점

setApprovalForAll()을 잘 모르는 서비스에 승인하면 해당 컨트랙트 안에서 사용자가 가진 여러 토큰이 탈취될 수 있다.<br />또한 여러 종류의 토큰을 한꺼번에 전송하는 만큼 tokenId와 수량을 정확하게 확인해야 한다.

#### 핵심 이벤트

ERC-1155는 토큰의 이동과 권한 변경을 블록체인 로그에 남기도록 이벤트를 정의한다.

- <b>TransferSingle</b> : 한 종류의 토큰이 전송, 발행 또는 소각될 때 기록
- <b>TransferBatch</b> : 여러 종류의 토큰이 한 번에 이동할 때 기록
- <b>ApprovalForAll</b> : 전체 토큰 관리 권한이 설정될 때 기록
- <b>URI</b> : 특정 tokenId의 메타데이터 주소가 변경될 때 기록

#### 토큰 발행과 소각

ERC-1155에서도 새로운 tokenId와 수량을 발행하거나 기존 토큰을 소각할 수 있다.

```solidity
민팅
tokenId 2 회복 물약 10개 생성

소각
tokenId 2 회복 물약 3개 제거
```

ERC-1155 표준이 누구나 사용할 수 있는 mint()와 burn() 함수를 반드시 요구하는 것은 아니다.<br />누가 토큰을 발행하거나 소각할 수 있는지는 각 프로젝트가 직접 정한다.

#### 메타데이터

ERC-1155에서는 일반적으로 uri(id)를 이용해 각 tokenId의 메타데이터 위치를 확인한다.

```solidity
tokenId
   ↓ uri(id)
메타데이터 JSON
   ↓
이름, 설명, 이미지, 속성
```

여러 tokenId가 하나의 URI 형식을 공유할 수 있기 때문에 토큰 종류가 많아도 메타데이터를 효율적으로 관리할 수 있다.

#### 사용 사례

ERC-1155는 여러 종류의 자산을 한꺼번에 관리하는 서비스에 적합하다.

```solidity
게임 화폐와 아이템
일반 아이템과 희귀 아이템
공연 및 행사 입장권
멤버십과 쿠폰
여러 종류의 디지털 수집품
ENS 이름과 하위 도메인
```

#### 실제 이더리움 메인넷 사례 - ENS Name Wrapper

ENS Name Wrapper는 ENS 이름과 하위 도메인을 ERC-1155 토큰 형태로 관리하는 메인넷 컨트랙트이다.

- 컨트랙트 주소 : <code>0xD4416b13d2b3a9aBae7AcD5D6C2BbDBE25686401</code>
- [ENS Name Wrapper Etherscan에서 확인하기](https://etherscan.io/token/0xd4416b13d2b3a9abae7acd5d6c2bbdbe25686401)

각 ENS 이름은 서로 다른 tokenId로 구분되며, 하나의 ERC-1155 컨트랙트에서 여러 이름과 하위 도메인을 관리한다.<br />Etherscan에서는 tokenId별 소유자와 실제 전송 기록, TransferSingle과 TransferBatch 이벤트 등을 확인할 수 있다.

즉, ERC-1155는 여러 종류의 토큰을 하나의 컨트랙트에서 관리하고 한 번에 조회하거나 전송할 수 있도록 만든 효율적인 멀티 토큰 표준이다.

#### 한 줄 정리

> ERC-1155는 여러 종류와 수량의 토큰을 하나의 컨트랙트에서 관리하고 일괄 처리할 수 있도록 만든 멀티 토큰 표준이다.
